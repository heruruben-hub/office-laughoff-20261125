## The joke

> I asked IT for a raise and they told me to turn my salary off and on again.

The setup sounds like a normal pay-rise request, then the punchline lands on
the most famous IT fix of all time — rebooting — applied to the one thing no
one can reboot: your salary.

## How it works

`main.ts` writes the single-line joke (75 characters) to `/output/entry.txt`
when run with Node:

```sh
node main.ts
```
